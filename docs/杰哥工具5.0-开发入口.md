# 杰哥工具 5.0 开发入口

- 5.0 基线来源：杰哥工具 4.0 最终归档版 `v2026.08.10.3`。
- 当前版本：`v2026.08.20.3`，浙江仓修补剂折叠标题新增明确的展开/收起按钮。
- 建立日期：2026-08-10。
- 4.0 历史业务规则：见 `杰哥工具4.0-需求归档.md`。
- 当前回归基线：47 项。
- 后续所有新功能、价格调整和规则修改只在本目录进行。
- 每次修改应在本文件追加简短记录，避免再次依赖超长 Codex 对话恢复上下文。

## 变更记录

### v2026.08.20.3

- 修补剂合计右侧新增真实按钮，收起时显示“点击展开”，展开后显示“点击收起”，并同步方向箭头。

### v2026.08.20.2

- 浙江仓修补剂区域默认折叠，点击标题后才展开，减少非修补剂订单的页面占用。
- 四个规格的选项与数量改为同行排列，删除单项小计，只在折叠标题中实时显示修补剂合计。

### v2026.08.20.1

- 文字报价输入星云石B款等宁波产品时只自动带出规格，不再把底价写入“折扣优惠价”；单产品与多产品的优惠价均由用户手填并保持可修改。
- 浙江仓附加工艺新增修补剂：50g/15元、100g/30元、200g/50元、500g/125元。
- 修补剂支持四种规格任意组合，每项勾选默认数量1且可独立修改；金额自动写入开单明细并扣入KD。

### v2026.08.19.1

- 宁波仓产品名称由“20内圆”正式统一为“20圆柱”，底价 95元/㎡，规格 3000×1200mm。
- “30内圆”底价由错误的 95元/㎡修正为 90元/㎡，规格保持 3000×1200mm。
- 开单模板、文字报价、快速查价和宁波重量同步刷新公共产品数据缓存版本；文字报价单产品/多产品切换时会自动刷新对应宁波底价，原始价格表也完成名称修正并归档。

### v2026.08.15.1

- 顺心捷达统一切换为用户提供的嘉兴发全国最新报价表，覆盖四个重量档和27个地区。
- 三个顺心捷达入口同步刷新公共脚本缓存版本，并统一显示报价表中的条件费用提示。
- 原始报价表归档为 `顺心捷达最新报价表-20260815.xlsx`，后续费率调整继续只维护公共数据和核心。

### 5.0 基线

- 文字报价始终显示顺心捷达自动报价窗口。
- 开单模板在浙江仓鎏金板模式下始终显示顺心捷达自动报价窗口，不依赖物流选择。
- 保留 4.0 的全部共享价格、DB、宁波合装、混凝土费用、报价历史和完整包规则。
