# 杰哥工具 5.0 开发入口

- 5.0 基线来源：杰哥工具 4.0 最终归档版 `v2026.08.10.3`。
- 当前版本：`v2026.08.27.1`，浙江仓新增按数量计费的辅料选项。
- 建立日期：2026-08-10。
- 4.0 历史业务规则：见 `杰哥工具4.0-需求归档.md`。
- 当前回归基线：62 项，并完成开单、文字报价、宁波重量、上墙排版和报备模板布局验收。
- 后续所有新功能、价格调整和规则修改只在本目录进行。
- 每次修改应在本文件追加简短记录，避免再次依赖超长 Codex 对话恢复上下文。

## 变更记录

### v2026.08.27.1

- 浙江仓新增胶水、保护剂1KG、保护剂5KG三种辅料，价格分别为15元/支、40元/瓶、145元/桶。
- 三种辅料默认不勾选；勾选后才显示数量输入框，按实际填写数量计费，自动写入开单明细并扣入KD；切换仓库不收费，“重置下一个”会清空全部辅料选项和数量。

### v2026.08.25.3

- 混凝土倒边费由平方计费改为长度计费：松诺 10 元/米、168 为 5 元/米。
- 开单模板改为填写实际倒边总米数，明细单位同步写“米”；快速查价中的松诺和168附加费说明同步更新。

### v2026.08.25.2

- 水泥板/混凝土选择或手填“支付宝-TM绿活材料美学馆旗舰店”时，自动按合计的 1.3% 计算扣点；付款文字尾部带账号括号时同样识别。
- 扣点以“扣点：金额元”写入开单明细，并继续从 KD 中扣除；付款方式变化会恢复自动生成，避免指标卡已更新而正文停留在旧 KD。

### v2026.08.25.1

- 开单模板“重置下一个”现在会把加工费明确设为 0，再重新计算税金、KD 和合计，避免上一单加工费串入下一单。
- 新增加工费重置回归检查，自动回归基线更新为 61 项。

### v2026.08.24.3

- 报备模板顶部重置按钮缩小后移到“基础信息”右上角，替换原月份浅灰提示，并改为蓝色背景、白色字体。
- 生成结果区域原有“一键重置”恢复保留，顶部和结果区两个按钮共用同一重置逻辑。

### v2026.08.24.2

- 报备模板“一键重置”移到页面最上方右侧，位置与开单模板顶部重置操作保持一致；生成结果区域只保留“一键复制”。
- 窄屏下重置按钮自动占满一行，避免挤压标题或产生横向溢出。

### v2026.08.24.1

- 顺心捷达地址改为省级行政区优先；道路名不误判，多省歧义转人工确认；非标准厚度不再回退标准规格。
- 开单模板删除独立鎏金包装分支，统一使用公共运费核心；修正硬软混装、多只小托盘、空白附加产品、货拉拉 DB 与说明文字。
- 宁波产品建立规格级价格映射；20圆柱/30内圆价格、规格、重量联动；未知规格和缺失重量必须人工填写。
- 混凝土价格统一到公共数据；手工单价可保留；动态增加商品不再清空旧输入。
- 修补剂只在浙江仓鎏金板启用；砂岩附加工艺正常计费；付款扣点以最终付款方式文本为准。
- 上墙留缝保留整板宽度，不再出现1397mm被均分为930mm；修正首页、上墙表格和报备模板移动端布局。
- 1200×600 小托盘因缺少权威长宽高继续人工询价，本版未猜测尺寸。

### v2026.08.22.1

- 浙江仓选择货拉拉时，DB 改为写入货物明细后的开单正文，并从 KD 中扣除。
- 货拉拉开单正文仍不显示重量公式和包装行；上方重量/包装核算与下方运费提问保留。

### v2026.08.20.3

- 修补剂合计右侧新增真实按钮，收起时显示“点击展开”，展开后显示“点击收起”，并同步方向箭头。

### v2026.08.20.2

- 浙江仓修补剂区域默认折叠，点击标题后才展开，减少非修补剂订单的页面占用。
- 四个规格的选项与数量改为同行排列，删除单项小计，只在折叠标题中实时显示修补剂合计。

### v2026.08.20.1

- 文字报价输入星云石B款等宁波产品时只自动带出规格，不再把底价写入“折扣优惠价”；单产品与多产品的优惠价均由用户手填并保持可修改。
- 浙江仓附加工艺新增修补剂：50g/15元、100g/30元、200g/50元、500g/125元。
- 修补剂支持四种规格任意组合，每项勾选默认数量1且可独立修改；金额自动写入开单明细并扣入KD。

### v2026.08.19.1

- 宁波仓产品名称由“20内圆”正式统一为“20圆柱”，底价 95元/㎡，规格 3000×1200mm。
- “30内圆”底价由错误的 95元/㎡修正为 90元/㎡，规格保持 3000×1200mm。
- 开单模板、文字报价、快速查价和宁波重量同步刷新公共产品数据缓存版本；文字报价单产品/多产品切换时会自动刷新对应宁波底价，原始价格表也完成名称修正并归档。

### v2026.08.15.1

- 顺心捷达统一切换为用户提供的嘉兴发全国最新报价表，覆盖四个重量档和27个地区。
- 三个顺心捷达入口同步刷新公共脚本缓存版本，并统一显示报价表中的条件费用提示。
- 原始报价表归档为 `顺心捷达最新报价表-20260815.xlsx`，后续费率调整继续只维护公共数据和核心。
