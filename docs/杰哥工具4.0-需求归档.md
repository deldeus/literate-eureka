# 杰哥工具 4.0 需求归档

归档日期：2026-08-10  
归档状态：4.0 已封版；后续修改只在“杰哥工具5.0”继续。  
历史 Codex 任务：`019efd9c-a60f-7513-ac1c-11d24fa0b74f`（归档后不再继续追加上下文）。

## 一、长期维护原则

1. 任何涉及同一业务的修改，都必须检查并同步所有相关子工具，不能只改一个页面。
2. 产品价格统一维护在 `tools/product-data.js`；鎏金运费/DB/顺心捷达统一维护在 `tools/freight-gold-core.js`；宁波合装运费统一维护在 `tools/ningbo-freight-core.js`。
3. 页面引用公共脚本时必须更新缓存版本号，避免 GitHub Pages 继续加载旧文件。
4. 不支持或无法识别的规格必须提示人工确认，不能偷偷回退成默认规格。
5. 每次交付必须提供完整 GitHub 包，包含首页、全部 `tools`、公共 JS、图片资源、上传说明和回归测试；不能只发单个 HTML。
6. 每次修改后运行完整回归测试，并实际检查受影响页面；优先修改同一份主版本，避免堆叠多个检查副本。

## 二、工具入口

- 开单模板：浙江仓、宁波仓、混凝土仓、水泥板仓库、自选仓的开单与费用核算。
- 文字报价：单产品/多产品报价、费用、税金、历史记录、鎏金运费提问和顺心捷达自动报价。
- 快速查价：鎏金板、宁波柔岩、混凝土等产品价格与规则说明。
- 报备模板：项目报备内容生成。
- 孔心排版：1200×600 板孔位计算与 SVG 导出。
- 鎏金运费：多规格重量、包装、DB、顺心捷达自动报价。
- 宁波重量：多产品合装重量与木箱尺寸计算。
- 整板切割：小板需求换算整板用量和排版。
- 上墙排版：多墙面、孔位、裁切统计及 SVG/PNG 导出。

## 三、浙江仓、鎏金板与 DB

### DB 计费

- 小板（短边不超过 600、长边不超过 1200）：`0.5元/片`。
- 中板（短边不超过 600、长板规格）：`0.75元/片`。
- 大板：`1.5元/片`。
- 混装逐项累计，最终四舍五入为整数，单票封顶 `100元`。
- 开单模板、鎏金运费、文字报价必须共用同一 DB 核心。

### DB 在开单中的位置

- 浙江仓只有“跨越”不代收 DB：DB 写入开单正文并从 KD 中扣除。
- 顺心捷达、姜冉、西武及其它非跨越物流：DB 放在开单正文下方的运费明细中，不从 KD 扣除。
- 货拉拉/自提时，完整开单正文隐藏重量、包装和 DB；上方核算及下方运费提问仍保留。

## 四、顺心捷达自动报价

1. 三个入口共用 `shunxin-rates.js` 与 `freight-gold-core.js`：鎏金运费、开单模板、文字报价。
2. 开单模板只要是“浙江仓 + 鎏金板”就始终显示顺心捷达窗口，不依赖物流是否勾选顺心捷达。
3. 文字报价始终保留顺心捷达窗口；未填写鎏金产品时显示填写提示，填写后自动计算。
4. 计费重量取实际重量与体积重量的较大值；体积重量公式：`长×宽×高×200`。
5. 按 `100–500KG`、`501–999KG`、`1000–1500KG` 档位匹配费率；特殊地区或超范围转人工询价。
6. 托盘自动报价限制：三边和不超过 `4.8m`、高度不超过 `1.8m`、实际重量不超过 `1000KG`。
7. 保费：货值 `≤2000元` 默认 `5元`；超过 2000 元按货值 `0.003` 计算。开单模板和文字报价自动读取总价；鎏金运费由用户填写货值，未填按 5 元。
8. 上门费：`≤40KG` 免费；超过 40KG 按 `25元 + 0.1元×计费重量`。默认不勾选，但金额始终显示；勾选后才并入运费合计。
9. 顺心捷达报价合计包含基础运费、保费、DB，以及勾选后的上门费，并显示完整计算过程。

## 五、产品数据与快速查价

- 鎏金、砂岩、宁波产品的规格与价格尽量只保留在公共产品数据中，开单、查价和报价共同读取。
- “大漠沙丘……珠光白”中的“珠光白”是颜色，仍按大漠沙丘系列计价；单独输入“珠光白”才按珠光系列。
- 快速查价中 8 个鎏金系列同时展示底价和最低售价，最低售价不能改写共享底价。
- 同名产品来自不同仓库时，快速查价必须同时保留结果并标明仓库来源。

## 六、宁波重量与运费

- 宁波重量工具支持加入多个不同产品/规格，同票尽量合装一个木箱。
- 木箱宽、长分别取所有产品最大值后各加 `100mm`。
- 木箱高度按各产品厚度×数量累计，再加 `200mm`。
- 合装只计算一次包装重量，总重量为所有产品重量加一个木箱重量。
- `1200×600` 即使带厚度文字也必须识别为小板规格。
- 宁波重量与开单模板必须使用同一宁波运费核心；输出尺寸顺序保持“宽×长×高”。

## 七、混凝土仓规则

### 松诺

- 打孔：`7元/㎡`。
- 倒边：`10元/㎡`。
- 超过 20 个规格的多尺寸费：`10元/㎡`。

### 168

- 打孔：`5元/㎡`。
- 倒边：`5元/㎡`。
- 干挂孔：`1元/个`。
- 干挂件：`8元/个`。
- 30 种规格以上的多尺寸费：`10元/㎡`。
- 168 清水板、透光板订单总面积 `<5㎡` 时自动加包装费：小板 `1200×600` 为 `100元`；大板 `1200×2400` 或任一单件面积 `≥1.5㎡` 为 `150元`；混合规格取 150 元。
- 总面积 `≥5㎡` 不自动加包装费；旧的统一 200 元规则已取消。
- 开单模板和快速查价中的规则说明必须同步。

## 八、文字报价与界面行为

- 空产品不能误判为鎏金板，但顺心捷达窗口仍需显示填写提示。
- 历史记录只在成功点击“复制报价”后保存完整报价；普通输入、改字和自动刷新不保存。
- 相同报价重复复制时去重并置顶；最多保留 40 条，保留载入和删除功能。
- 所有数字输入框需阻止鼠标/触控板滚轮误改数值。
- 空白开单不显示包装超量警告；宁波仓使用宁波专用提示。
- 整板切割与上墙排版保持统一标题、控件高度和窄屏不横向溢出。

## 九、交付与验收

- 正式上传 GitHub 时必须完整覆盖仓库根目录，至少包含 `index.html`、`README-上传说明.txt`、完整 `tools/`；建议同时上传 `tests/` 和 `docs/`。
- `tools/assets/shunxin-jieda-logo.png` 不可遗漏。
- 当前回归测试文件：`tests/regression.test.js`。
- 如本文与后续用户的新要求冲突，以后续明确要求为准，并同步更新本档案与测试。
