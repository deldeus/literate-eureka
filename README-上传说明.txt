杰哥工具完整版本：5.0 · v2026.08.19.1（基线源自 v2026.08.10.3）

本次更新：
- 宁波仓“20内圆”正式更名为“20圆柱”，底价统一为95元/㎡，规格3000×1200mm。
- 宁波仓“30内圆”底价统一修正为90元/㎡，规格3000×1200mm。
- 开单模板、文字报价、快速查价和宁波重量全部共用最新公共产品数据；文字报价单产品/多产品切换时会自动刷新宁波底价，价格表已同步修正并归档在docs目录。
- 上墙排版新增板间留缝：0、1、2、3、4、5、10mm 和自选填写；仅板材之间扣除缝隙，墙体四周不预留。
- 留缝会同步影响板块实际尺寸、裁切统计、图纸显示以及 SVG/PNG 导出结果。
- 上墙排版“板材参数”改为左侧“板宽 mm”、右侧“板高 mm”，对应板子的横向宽度和竖向高度。
- 开单模板付款方式新增“T农行”，选择后会自动写入付款方式结果和完整开单正文。
- 顺心捷达的货值、上门服务、保价费用和上门费用统一为四列栅格，标题与控件等高对齐；窄屏自动切换为两列或单列。
- 上述排版已同步到鎏金运费、文字报价和开单模板三个入口。
- 文字报价中的顺心捷达自动报价窗口改为始终显示；未填写鎏金板时保留填写提示，不再整块隐藏。
- 开单模板只要选择“浙江仓 + 鎏金板”就始终显示顺心捷达自动报价窗口，不依赖物流是否选择顺心捷达。
- 浙江仓选择“货拉拉”或“自提”时，完整开单正文不再显示重量公式、包装尺寸和 DB；上方核算结果、KD/DB 计算及下方运费提问保持不变。
- 开单模板浙江仓物流新增“安能”，并保留“顺心捷达”；仓库切换后自动恢复对应仓库的默认物流选项。
- 鎏金运费中的原物流自动查询已完整替换为“顺心捷达自动报价”。
- 顺心捷达价格已更新为 2026-08-15 用户提供的《顺心捷达最新报价表（嘉兴发全国）》，同步四个重量档、27个地区、特殊区域和附加条件。
- 顺心捷达自动报价已同步到三个位置：鎏金运费、浙江仓鎏金板开单、文字报价中的鎏金板。
- 三个位置共同读取 tools/shunxin-rates.js 和 tools/freight-gold-core.js，后续修改只需维护同一套公共数据和逻辑。
- 自动报价按实际重量与体积重量取较大值，再匹配 100-500KG、500-999KG、1000-2000KG、2000KG以上四个报价区间，并显示完整计算过程。
- 计费重量低于100KG、地址未匹配或报价表标记为特殊区域时，会停止自动计算并提示人工询价。
- 到付、代收货款和月发货量不足200吨属于需要订单条件才能确定的附加费用，三个入口都会显示最新规则提示，当前不会擅自并入普通报价。
- 已删除旧物流相关界面、脚本引用和报价数据。
- 顺心捷达 Logo 已放在 tools/assets/shunxin-jieda-logo.png。

本完整包同时保留此前已经确认的全部功能：
- 宁波多产品合装、最大长宽木箱核算及开单联动。
- 鎏金运费公共包装和 DB 核算。
- 文字报价只在复制完整报价后写入历史记录。
- 快速查价鎏金板底价与最低售价展示。
- 混凝土 168 仓附加工艺和自动包装费规则。
- 所有数字输入框已拦截触控板滚轮误改数值。

GitHub Pages 覆盖方法：
1. 推荐直接上传“杰哥工具5.0-GitHub完整包-20260819”文件夹内的全部内容，并保持原目录结构。
2. index.html、README-上传说明.txt、AGENTS.md、tools、docs、tests 均属于完整包；tools 内的 JS 和 assets 不能遗漏。
3. 必须选择覆盖同名文件，不能只上传单个 HTML。
4. 上传后等待 GitHub Pages 部署完成，再强制刷新网页，避免浏览器继续使用旧缓存。
