GitHub Pages 覆盖方法：
1. 把本文件夹里的 index.html、README-上传说明.txt 和整个 tools 文件夹一起上传到仓库根目录。
2. 必须选择覆盖同名文件，不能只上传单个 HTML，也不能遗漏 tools 内的 JS 和 assets 文件。
3. 上传后等待 GitHub Pages 部署完成，再强制刷新网页，避免浏览器继续使用旧缓存。
